# Demo Project Before

Before running AI Team Agent Kit, a repository may have source code and ordinary project documentation, but no shared operating model for AI-assisted work.

Common gaps:

- no `AGENTS.md`
- no coding-agent instructions
- vague pull request review
- no structured security review prompt
- no product value review prompt
- no business automation discovery prompt
- no employee automation training
- no AI workflow playbook
- no pull request checklist for AI assistance, risk, tests, and rollback

Example review request:

```text
Review this code.
```

That request is too broad. It does not tell the reviewer which risks to inspect, which roles to use, how to handle product value, or when to escalate to a human.

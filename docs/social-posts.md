# Social Posts

## LinkedIn

I launched AI Team Agent Kit, a lightweight open-source toolkit for teams adopting AI coding agents, structured pull request review, and business automation workflows.

Most teams use AI chaotically: vague prompts, inconsistent code review, missing safety rules, and no shared workflow.

AI Team Agent Kit adds a reusable AI-agent operating system to any GitHub repository in seconds:

```bash
npx ai-team-agent-kit init
```

It creates `AGENTS.md`, Codex/Copilot-style instructions, reusable prompt files, sub-agent pull request review workflows, product value review prompts, security review prompts, business automation discovery prompts, employee AI training materials, and an AI workflow playbook.

It is not another AI code reviewer. It does not call an LLM. It does not require an API key.

It gives developers, founders, engineering managers, open-source maintainers, and AI automation consultants a practical structure for safer and more consistent AI-assisted work.

GitHub: https://github.com/romanigoliro-stack/ai-team-agent-kit

npm: https://www.npmjs.com/package/ai-team-agent-kit

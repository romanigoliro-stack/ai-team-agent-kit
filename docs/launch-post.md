# Launch Post

I built AI Team Agent Kit, a lightweight open-source toolkit for teams adopting AI coding agents, structured pull request review, and business automation workflows.

Most teams use AI chaotically: vague prompts, inconsistent review, missing safety rules, and no shared workflow.

AI Team Agent Kit adds a reusable AI-agent operating system to a repository in seconds:

- `AGENTS.md`
- Codex/Copilot-style instructions
- multi-role pull request review prompts
- product value review prompt
- business automation discovery prompt
- employee AI automation training guide
- AI workflow playbook

Try it:

```bash
npx ai-team-agent-kit init
```

It is for developers, founders, engineering managers, open-source maintainers, and AI automation consultants who want teams to move from random AI chats to structured AI-assisted work.

Link: https://github.com/romanigoliro-stack/ai-team-agent-kit

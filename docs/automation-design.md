# Спроектируй автоматизацию до того, как начнёшь её собирать

Скилл «Проектирование автоматизации» помогает превратить идею в готовое задание для Codex. Он задаёт вопросы по одному, уточняет правила, данные и инструменты, затем составляет план разработки с проверками.

## 1. Установи скилл

Открой Codex в обычном режиме, без Plan mode. Скопируй и отправь это сообщение:

```text
$skill-installer

Установи скилл из этого репозитория:
https://github.com/romanigoliro-stack/ai-team-agent-kit/tree/main/skills/automation-design-interview
```

После сообщения об успешной установке открой новый чат. Если скилл не появился в списке, перезапусти Codex. Установка выполняется один раз; npm-команды из основной страницы репозитория для этого скилла не нужны.

## 2. Включи планирование и назови задачу

В новом чате включи Plan mode командой `/plan`. Затем отправь:

```text
$automation-design-interview

Хочу автоматизировать расчёт зарплаты сотрудников по KPI.
Сейчас считаю вручную в таблице.
Помоги спроектировать первую версию. Задавай вопросы по одному.
```

Замени пример своей задачей. Например: «Хочу готовить список закупок для кофейни по остаткам в iiko». Готовый документ, архитектура и список инструментов заранее не нужны.

Скилл можно выбрать через `$` по имени `automation-design-interview`; отображаемое название: «Проектирование автоматизации».

## 3. Ответь на вопросы

Рассказывай, как делаешь работу сейчас, откуда берёшь данные, по каким правилам принимаешь решения и какой результат хочешь получить. Если чего-то не знаешь, так и напиши.

Ориентир: около 10 минут беседы. Обычно 6-8 вопросов, максимум 10 с уточнениями. Проверка сложных подключений может потребовать больше времени. Используй вымышленные примеры, не отправляй пароли и настоящие конфиденциальные данные.

## 4. Отправь план в разработку

В конце получишь одно задание: что строим, какие данные используем, как работают отдельные части, в каком порядке собираем и как проверяем результат.

Прочитай формулы, примеры и предложенные правила. Исправь то, что не соответствует твоей работе. Затем скопируй весь итоговый блок в новый чат Codex в обычном режиме и отправь на реализацию.

В Plan mode план появится в сообщении. В обычном режиме скилл также может сохранить его в `AUTOMATION_PLAN.md`. Файл не обязателен для передачи: вся необходимая информация должна быть в копируемом блоке.

## Если потерялся

Напиши Codex:

```text
Объясни следующий шаг простыми словами.
Покажи, что ты понял о моей задаче и где остались пробелы.
Не придумывай правила за меня.
```

Скилл помогает проектировать автоматизации и агентов. Он сам не запускает бизнес-процесс, не отправляет заказы и не проводит платежи.

# AI Team Agent Kit Pitch

## One-liner

AI Team Agent Kit helps teams turn chaotic AI usage into structured AI-assisted development and business automation workflows.

## Problem

Teams are adopting AI coding agents quickly, but most do not have shared rules, review prompts, safety boundaries, or employee training materials.

## Solution

AI Team Agent Kit adds a reusable AI-agent operating system to any repository in seconds.

It creates:

- project-level agent rules
- coding-agent instructions
- pull request review prompts
- product value review workflows
- automation discovery prompts
- employee training materials
- an AI workflow playbook

## Target users

- developers
- founders
- CTOs
- engineering managers
- open-source maintainers
- AI automation consultants
- teams teaching employees how to use AI in business workflows

## Core value

- improves AI output quality through shared instructions
- standardizes pull request review
- adds product-value thinking to technical work
- helps employees identify automation opportunities
- requires no API key or paid integration
- works with existing tools immediately

## Uniqueness

This is not an AI code reviewer. It does not call an LLM. It gives teams the structure, prompts, instructions, and workflows needed to use AI coding agents safely and consistently.

## Demo flow

1. Open a repository without AI workflow files.
2. Run `npx ai-team-agent-kit init`.
3. Show the generated `AGENTS.md`, prompts, agent roles, pull request template, training guide, and playbook.
4. Run `npx ai-team-agent-kit check`.
5. Show the setup score and recommendations.

## Roadmap

- more template packs
- continuous integration check mode
- project-specific variables
- maintainer workflow examples
- employee automation workshops

## Why now

AI coding agents are becoming normal in software teams, but team operating models are lagging behind. The next step is not more random prompting. The next step is shared, reviewable, reusable AI workflows.

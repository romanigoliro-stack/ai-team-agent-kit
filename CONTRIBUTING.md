# Contributing

Thanks for helping improve AI Team Agent Kit.

This project is meant to stay small, practical, and dependency-free. The best contributions make the generated workflow files more useful for real software teams.

## Contributions welcome

- clearer AI agent instructions
- better pull request review prompts
- stronger security and safety guidance
- practical product-value review examples
- employee automation training exercises
- documentation improvements
- bug fixes in template copying or setup checks
- command output improvements

## Local checks

Run:

```bash
npm run smoke
npm pack --dry-run
```

The project intentionally uses built-in Node.js modules only. Please avoid adding dependencies unless there is a strong reason.

## Template style

Templates should be:

- practical
- specific
- easy to scan
- safe by default
- useful without paid tools
- adaptable across many repositories

Avoid:

- vague advice
- hype-heavy language
- tool-specific instructions that exclude other agents
- prompts that ask agents to invent business requirements
- unsafe automation guidance without human approval boundaries

## Pull requests

Please include:

- what changed
- why it matters
- how it was tested
- any risks or tradeoffs

Small, focused pull requests are easier to review.

# Code of Conduct

## Our pledge

We want this project to be a practical and respectful place for maintainers, contributors, and users.

Participants are expected to:

- be respectful and constructive
- assume good intent while addressing impact
- focus feedback on ideas, code, documentation, and user value
- avoid harassment, insults, or discriminatory language
- help keep discussions useful for the project

## Unacceptable behavior

Unacceptable behavior includes:

- personal attacks
- harassment or intimidation
- discriminatory language
- publishing private information without permission
- repeated off-topic disruption

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants when behavior harms the project or community.

## Reporting

Report conduct concerns to the maintainers through the repository's private contact or security reporting channel when available.

# Changelog

## v0.1.0

Initial release of AI Team Agent Kit.

### Added

- `init` command for copying AI-agent workflow files into a repository.
- `check` command for scoring the recommended setup from 0 to 100.
- `AGENTS.md` project-level AI agent rules.
- Codex/Copilot-style coding-agent instructions.
- Multi-role pull request review prompt.
- Product value review prompt.
- Business automation mapping prompt.
- Agent role definitions for code review, product value review, and automation coaching.
- Pull request template with AI assistance, risk, tests, and rollback sections.
- Employee AI automation training guide.
- AI workflow playbook.
- Open-source community files and launch materials.

### Notes

- Uses Node.js 18+ and built-in Node.js modules only.
- Does not call external APIs.
- Does not call model providers.
- Does not require an API key.
